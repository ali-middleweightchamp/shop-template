# Page Rules: Catalog (товарная сетка)

> **Приоритет:** эти правила **перебивают** `MASTER.md` для страниц каталога,
> категории, поиска и блоков с сеткой товаров. Общая нейтраль, шрифты, шкала
> отступов и a11y — берутся из `MASTER.md`.

Цель страницы: покупатель с телефона собирает заказ из 10–20 позиций. Нужно
видеть **много товаров сразу**, быстро попадать пальцем по «+», колонки не должны
«прыгать». Плотность и предсказуемость важнее декоративности.

---

## 1. Сетка

- Колонки: **2** до `640px`, **3** до `1024px`, **4** выше.
- Gap: **12px** на мобильном, **16px** на десктопе (значения только из шкалы).
- Контейнер: `max-width: 1120px`, боковой падинг 16px.
- Категории над сеткой — **горизонтальная лента чипов** с прокруткой пальцем
  (`overflow-x:auto`, скрытый скроллбар). **Не** выпадающее меню и **не** боковая
  колонка. Активный чип — заливка `--color-fg`, текст белый.

## 2. Карточка — равная высота (главное правило)

- `display:flex; flex-direction:column; height:100%`. Родитель-ячейка сетки
  тянет карточку на всю высоту ряда → **все карточки в ряду одной высоты**
  независимо от длины названия и пропорций фото.
- Блок цены + кнопок прижат к низу: `margin-top:auto` на нижней секции.
- Внутренний падинг тела карточки — 12px. Радиус — `--radius-card` (14px).
  Тень — `--shadow-card`. Без hover-скейла, сдвигающего соседей.

## 3. Фото

- Контейнер: `aspect-ratio: 1/1`, `object-fit: contain`, фон `#FFFFFF`,
  padding **8px**. Одинаковый квадрат для любых пропорций оригинала.
- В списках отдавать **только превью** (thumbnail 400×400), не оригиналы.
- `loading="lazy"`, заданы `width/height` (или aspect-ratio) — без сдвигов при загрузке.

## 4. Название

- `line-clamp: 2` + **фиксированная `min-height` под две строки**
  (`≈ 2 × line-height`). Короткое название **не поднимает** цену — низ карточки
  стоит на месте у всех.
- Размер 14px, вес 700, цвет `--color-fg`.

## 5. Цена

- `font-variant-numeric: tabular-nums` — иначе колонка цен «пляшет».
- Цена — 16px/800 `--color-fg`; единица и валюта — `--color-muted`.
- Старая цена (если есть) — `--color-muted`, зачёркнута.
- Если `show_prices=false` — «Цена по запросу», `--color-muted`.

## 6. Счётчик «− N +»

- Каждая зона нажатия (`−`, `+`) минимум **44×44px**.
- Значение — по центру, `tabular-nums`.
- Активное состояние (в корзине > 0): рамка/подсветка `--shop-primary`.
- Растянут по ширине тела карточки (`width:100%`, `justify-content:space-between`).

## 7. Нет в наличии

- Карточку **не прятать**. `opacity: .55`.
- Вместо счётчика — подпись «Нет в наличии» (нейтральная плашка), без кнопок.

## 8. Нет фото

- SVG-плейсхолдер: иконка + **первая буква категории** по центру квадрата
  (фон `--color-surface-2`, знак `--color-muted`). **Не** битая картинка и
  **не** пустой блок. Тот же `aspect-ratio 1/1`, что и у фото.

## 9. Плавающая панель корзины

- Высота **64px**, `position:fixed; bottom:0`.
- Учитывает `padding-bottom: env(safe-area-inset-bottom)`.
- Контент страницы получает **нижний отступ ≥ 96px** (64 + запас), чтобы панель
  **не перекрывала последний ряд** товаров.
- Показывается только когда в корзине есть позиции.

## 10. Запрещено на этой странице

- ❌ Разная высота карточек в ряду.
- ❌ Декоративные крупные карточки, отступы 48px+ между товарами.
- ❌ Оригиналы фото в списке.
- ❌ Прятать товары без наличия или без фото.
- ❌ Тач-таргеты < 44px, «пляшущая» колонка цен (не-tabular цифры).
- ❌ Хардкод акцента/названия/контактов — всё из `ShopSettings`.
